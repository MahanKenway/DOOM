Fully local physics game: Vector Putt 3D is a RetroPlay-built mini-golf runtime. The game selects a 3D WebGL renderer when the browser exposes one, and automatically provides a canvas physics view on compatibility-constrained devices, so the bundled courses remain playable without external assets.
